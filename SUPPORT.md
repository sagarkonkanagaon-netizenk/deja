# Getting help

1. Run `node <plugin dir>/bin/deja.mjs doctor`. It checks Node, the database, full-text search and whether hooks are firing.
2. Check the [troubleshooting table](README.md#troubleshooting) and `~/.deja/deja.log`.
3. Search [existing issues](https://github.com/sagarkonkanagaon-netizenk/deja/issues), then open one with the doctor output.

Questions and ideas are welcome in [Discussions](https://github.com/sagarkonkanagaon-netizenk/deja/discussions).
